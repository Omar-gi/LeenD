# لين — Leen

لين تجربة حوار عربية بالصوت والنص، تساعد في مواقف الصداقة بكلمات بسيطة ومراجع واضحة. صُممت لغة الحوار لسيناريوهات عمر ٩–١٠ سنوات؛ عرض الهاكاثون للبالغين باستخدام مواقف خيالية.

## المجالات

- اختيار الصديق
- الخلاف مع الصديق
- الغيرة والمقارنة
- الاستبعاد والتنمر

المحتوى من مرجع الفريق V1(4): 23 قيمة و32 مقتطفًا من الآيات والأحاديث. الاقتباسات تُملأ من النصوص المخزنة على الخادم؛ لا تُضاف مراجع دينية من المحادثة أو من ذاكرة النموذج. مراجعة الشرح وإرشادات السلامة ما زالت مطلوبة.

## التجربة

تسجيل حتى 30 ثانية، كتابة وتصحيح السؤال، رد صوتي ونصي، وروابط المراجع تحت الإجابة. تتحرك الشخصية حسب الاستماع والكلام. التحيات والختام قصيرة، والمتابعة تستخدم سياق الجلسة؛ إنهاء الجلسة أو تحديث الصفحة يمسح السياق المحلي.

## التقنيات

Next.js وTypeScript، OpenAI (`gpt-4o-mini-transcribe`) لتحويل الصوت إلى نص، وGPT-6 Luna لتكوين الإجابة ومراجعتها، ElevenLabs بصوت Nora، واستضافة Railway. قاعدة المعرفة ملفات JSON مستوردة من الإكسل؛ لا تدريب مخصص ولا قاعدة متجهات. اختيار المصادر وفحص الإجابة يقللان الأخطاء ولا يضمنان انعدام الهلوسة.

## التشغيل

يتطلب Node.js 22+ ومفاتيح API ممولة بشكل مستقل.

```sh
npm ci
cp .env.example .env.local
npm run dev
```

املأ `.env.local` محليًا، وفعّل `ENABLE_PAID_APIS` عند قبول تكلفة الاستخدام. لا ترفع المفاتيح إلى GitHub. على PowerShell استخدم `Copy-Item .env.example .env.local`. افتح http://localhost:3000. تفاصيل متغيرات الإنتاج في [دليل Railway](docs/RAILWAY.md).

```sh
npm test
npm run build
npm start
```
