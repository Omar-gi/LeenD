# Thmanyah font files

The owner supplied these four unmodified files for the local preview:

- `thmanyahsans-Regular.woff2`
- `thmanyahsans-Medium.woff2`
- `thmanyahsans-Bold.woff2`
- `thmanyahserifdisplay-Medium.woff2`

The project owner explicitly confirmed permission to include these font files in the GitHub repository on 2 October 2026. They are included on that basis, unmodified and under their original filenames. This statement records the owner's confirmation; it is not a new public font licence. The [official Thmanyah licence](https://font.thmanyah.com/licenses) remains separate from application code rights. Obtain fonts for other projects from [the official site](https://font.thmanyah.com/). No endorsement is implied.

The app uses Sans Regular, Medium and Bold for controls/body text and Serif Display Medium for headings. Other weights and the original briefing documents are not redistributed here.
